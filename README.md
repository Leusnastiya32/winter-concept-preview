# Зимний концепт главной страницы Chatcal Mountains

Показательный концепт для владельцев базы отдыха Chatcal Mountains (chatcal.uz).
**Это не официальный сайт.** Работа сделана по собственной инициативе, без заказа, и опубликована только для того, чтобы владельцы могли её посмотреть. По их просьбе страница будет сразу удалена.

## Как посмотреть
Открыть опубликованную страницу или скачать репозиторий и открыть `index.html` в браузере. Нужен интернет: шрифты, GSAP и Three.js подгружаются с CDN.

## Что внутри
- `index.html`: вся страница (вёрстка, анимации GSAP, 3D-фонари на Three.js).
- `assets/winter-*.jpg`: зимние версии фото базы, сделаны нейросетью из публичных фото с chatcal.uz. Здания и композиция сохранены, детали местами перерисованы.
- `assets/winter-real-cottages.jpg`: настоящее зимнее фото курорта из официального Инстаграма Chatcal Mountains (обрезано, надпись убрана).
- `assets/fireplace-warm.jpg`: настоящее фото каминного зала из того же Инстаграма, обработано нейросетью: зажжён огонь, убран кондиционер, добавлена маленькая веточка с огоньками на каминной полке, цвет теплее. Мебель и композиция сохранены, мелкие детали сервировки могли немного измениться.
- `assets/gen-parking.jpg`: картинка для блока «Бесплатная парковка», полностью сгенерирована нейросетью. Это общая сцена, а не фото самого места.

## Права
- Название, логотип, тексты, цены и исходные фото принадлежат владельцам базы. Логотип подключён ссылкой с chatcal.uz, в репозиторий не скопирован.
- Страница закрыта от индексации поисковиками (`noindex`).
- Тексты, цены и факты (с 2004 года, 6 домиков, цены в сумах) взяты с chatcal.uz и из открытых источников.

## Используемые библиотеки (подгружаются с CDN)
GSAP 3.12.5 + ScrollTrigger, Three.js 0.160.0 (MIT), шрифты Google Fonts (Montserrat, Playfair Display).
